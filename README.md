# Dhanvi Silks Ecommerce (Frontend + Admin)

A lightweight ecommerce storefront and admin dashboard for **Dhanvi Silks**.

## Features
- Product listing with category/search/price/sort filtering.
- Wishlist and shopping cart.
- Checkout flow that creates orders and updates stock.
- Admin login + dashboard with metrics.
- Product management (add/delete) and order list.
- Shared localStorage data between storefront and admin.

## Run locally
Because this project is static HTML/CSS/JS, you can open `index.html` directly.

For best experience, run a local static server:

```bash
python3 -m http.server 8080
```

Then open:
- Storefront: `http://localhost:8080/index.html`
- Admin: `http://localhost:8080/admin/index.html`
